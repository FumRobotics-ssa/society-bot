# گزارش بررسی نسخه تحویلی

تاریخ بررسی یازده نوامبر ۲۰۲۶

۲۳ تست خودکار با موفقیت اجرا شدند

تستها شامل ظرفیت همزمان و سقف هر کاربر و برگشت تراکنش ناقص و تکرار آپدیت و انقضا و مالکیت رسید و نقش تاییدکننده و ثبت ورود تکراری هستند

ثبت نام کامل و رد شماره متعلق به حساب دیگر و رزرو پولی و تایید مالک و اعلان لینک بلیت آزمایش شدند

ورود یکبار مصرف و ذخیره هش لینک ورود و کنترل Origin و لغو فوری مجوز نشست و جلوگیری از مشاهده کاربران توسط مسئول پذیرش آزمایش شدند

صف پایدار با خطای شبیه سازی شده ۴۲۹ تلگرام و ترتیب پردازش آپدیتهای هر کاربر آزمایش شد

انتقال دیتابیس قدیمی روی داده ساختگی و حفظ فایل اصلی و کد قدیمی و عدم انتقال نقش مدیر و بازیابی JSON روی مقصد خالی آزمایش شد

راه اندازی واقعی Node روی پورت محلی و مسیر health و فایلهای پنل و پاسخ ۴۰۱ API بدون نشست موفق بود

Wrangler dry run بسته Worker را بدون استقرار ساخت
ساختار دیتابیس شامل ۲۶ فرمان با Wrangler در D1 محلی اعمال شد

بررسی بصری مرورگر و اسکن با دوربین دستگاه واقعی انجام نشده است
تست بار روی حساب کلاد و اندازه گیری CPU پلن رایگان انجام نشده است
Bot API در تستها شبیه سازی شده و توکن واقعی استفاده نشده است
دیتابیس قدیمی واقعی و حساب Arvan و Cloudflare واقعی در اختیار پروژه نبوده است
بازیابی واقعی از باکت S3 باید پیش از اتکا به بکاپ ابری انجام شود
Docker در این محیط اجرا نشده است
