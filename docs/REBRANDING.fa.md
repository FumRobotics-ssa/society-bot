# تغییر نام سامانه به انجمن رباتیک

نام فارسی: انجمن رباتیک. نام انگلیسی: Robotics Society.
نام Worker و نشانی عمومی جدید از wrangler.toml خوانده می‌شوند.

## استقرار موجود در Cloudflare

۱. پیش از پوش کردن تغییر نام در گیت، با `npx wrangler login` وارد حساب موجود شوید.
۲. همان Worker موجود را از طریق تغییر نام در Cloudflare به robotics-society تغییر دهید؛ ساخت Worker جدا یا دیتابیس تازه لازم نیست.
۳. شناسهٔ دیتابیس و اتصال DB را حفظ کنید. دستورهای `npm run db:local` و `npm run db:remote` اکنون از نام اتصال DB استفاده می‌کنند.
۴. نسخهٔ جدید را روی Worker تغییرنام‌یافته منتشر کنید. اتصال گیت و نام Worker در تنظیمات ساخت نیز باید به همان Worker اشاره کنند.
۵. PUBLIC_URL را در فایل محلی .env و، در صورت وجود، .dev.vars با نشانی جدید هماهنگ کنید. توکن ربات و کلید وبهوک را تغییر ندهید.
۶. `npm run webhook` را اجرا و سپس نشانی برگشتی getWebhookInfo و سلامت مسیر /health را بررسی کنید.

آدرس قدیمی بنا به تصمیم مالک نگهداری نمی‌شود. لینک‌های ارسال‌شده با آدرس قبلی دیگر باز نمی‌شوند؛ لینک بلیت با همان توکن و آدرس جدید معتبر است.
ورود به پنل در آدرس جدید نیاز به دریافت یک لینک /admin تازه دارد. نام کوکی جدید robotics_society_session است.
داده‌ها، شناسهٔ دیتابیس، بلیت‌ها، وضعیت ورود و سطح دسترسی مدیران با تغییر نام عوض نمی‌شوند.

## اجرای محلی و Docker

نام فایل پیش‌فرض جدید data/robotics-society.sqlite است. برای دیتابیس موجود، DB_PATH را به همان فایل موجود تنظیم کنید؛ تغییر نام فایل باید پس از توقف سرور و حفظ فایل‌های WAL/SHM انجام شود.
اگر در پوشهٔ داده دیتابیس دیگری وجود داشته باشد، سرور به‌جای ساخت دیتابیس خالی خطا می‌دهد تا مسیر درست تنظیم شود.
نام سرویس Docker اکنون robotics-society و نام پیش‌فرض volume برابر robotics-society-data است.
برای استفادهٔ مجدد از volume قبلی، پیش از docker compose up مقدار ROBOTICS_DATA_VOLUME را به نام volume موجود و ROBOTICS_DB_PATH را به مسیر فایل موجود داخل /app/data تنظیم کنید. volume قبلی را حذف نکنید.

## ارجاع‌های تاریخی

نشانی منبع اصلی در NOTICE برای رعایت انتساب سازندگان حفظ می‌شود.
شناسهٔ فرمت بکاپ قدیمی و آزمون سازگاری آن باقی می‌مانند تا بکاپ‌های قبلی قابل بازیابی باشند؛ خروجی‌های جدید نام Robotics Society دارند.
نام واقعی دیتابیس ابری به شناسهٔ ثابت آن مربوط است و با تغییر نام برنامه، دیتابیس کپی یا دوباره ساخته نمی‌شود.
